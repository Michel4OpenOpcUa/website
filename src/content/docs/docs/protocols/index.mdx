Each protocol has four guides. The **overview** explains how the protocol works on the wire and which OT Fabric projects implement it. The **Go library** guide covers installing, connecting, reading, writing and error handling. The **CLI** guide walks through the command-line tool, for every protocol that has one. **Testing and interop** shows how each implementation is checked against independent reference stacks.

For a shorter introduction to a protocol, start with its page in the [protocol overview](/protocols/).
