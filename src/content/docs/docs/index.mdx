OT Fabric is an open-source ecosystem for industrial connectivity and interoperability: protocol **libraries**, field-ready **command-line tools** and **interoperability suites** for ten OT protocols, plus network visibility, desktop apps, captures and simulation. These docs explain how each protocol works and how to use every project.
